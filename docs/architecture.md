# Architecture

## Purpose

MitPortfolioWebsite is a personal portfolio website built as a practical
learning project.

The project is intentionally developed incrementally, starting with a
simple static website and evolving toward a more complete web application.

## Current architecture

The project currently contains documentation and Git configuration only.

No frontend framework, backend, API, or database has been introduced yet.

## Planned evolution

The architecture is expected to evolve through these stages:

1. HTML
2. CSS
3. JavaScript
4. React
5. Next.js
6. Backend/API
7. Database

Technology should only be introduced when there is a clear reason for it.
